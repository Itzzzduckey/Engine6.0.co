Engines

Layered detection.

Signature matching, behavior analysis and Windows’ own protection, working together instead of in isolation.

  • ShieldEngine. Behavior and content checks for processes, registry, persistence, network, browsers, Discord and files.
  • Engine 6.0. Signature matching against ShieldGuard’s own malware database, kept current by ShieldGuard signature downloads.
  • Windows Defender. Real-time protection plus quick and full scans.
  • Windows Firewall. Hardened inbound rules with logging.

What it does

Built to catch what hides.

ShieldGuard looks in the places malware actually uses, not just at files on disk.

Disguised programsExecutables posing as documents or pictures, double extensions, and fake system processes running from the wrong folder.
PersistenceStartup entries, scheduled tasks, services, WMI consumers and registry changes that let malware survive a reboot.
Script downloadersScripts that download or decode code, hide their commands or try to bypass Windows’ own scanning.
Browser and Discord tamperingSuspicious extensions, hijacked proxy settings and modified Discord loader files.
Command-and-control trafficLive connections from drop folders and DNS lookups of known malicious domains.
Infected projectsHidden build events and shellcode in source and project files, including Luckyware infections.

Protection

Always on, always visible.

Protection that works while you do, with every switch in plain view.

Real-time protection

Downloads, Desktop, Temp, Public and Startup folders are watched continuously. New files wait until the download finishes, then ShieldEngine and Engine 6.0 check them.

  • Every new process start is inspected
  • High-severity hits are quarantined and running programs stopped
  • Medium hits are logged only, so legitimate installers keep working

Download protection

On launch, ShieldGuard enables Windows’ supported download defenses.

  • Network Protection blocks known-malicious domains
  • Attack Surface Reduction rules block risky email and Office content
  • New executables are audited, not blocked, so installers still run
FirewallOne click applies all profiles on, unsolicited inbound blocked, and inbound blocks for SMB, NetBIOS, RPC, Telnet, FTP, RDP, VNC and WinRM. Dropped connections are logged, and you can block or unblock any IP address.
Antivirus switchesReal-time, behavior monitoring, script scanning, cloud protection, PUA, network protection, controlled folder access, archive, email and USB scanning, and scan timing.
Windows securitySmartScreen, Domain, Private and Public firewall profiles, User Account Control and memory integrity.
Attack surfaceRemote Desktop, Remote Assistance, SMBv1, AutoPlay and Windows Script Host. ON always means the protected side.
Verified changesEvery change is re-read from Windows, so a switch only stays moved if Windows really accepted it. Tamper Protection can’t be disabled by any program, so ShieldGuard explains it.

System InfoHardware, OS, network, services, processes, startup items and installed programs. Saved Wi-Fi passwords are never shown.
ConsoleLive engine activity and downloads checked, filterable by result and engine.
System trayMinimize to the tray or start with Windows, hidden. Startup uses a sign-in task, so there is no UAC prompt.
